## 🏗️ System Architecture
**Agentic DevSecOps Guard** runs 100% client-side inside the browser with zero backend servers, enforcing strict origin isolation and explicit user trust boundaries:

1. **Front-End Security Auditor (`security_auditor`)**: Scans Terraform and Infrastructure-as-Code (IaC) definitions in real time for critical IAM misconfigurations (`0.0.0.0/0` ingress exposure) and hardcoded credentials.
2. **FinOps Optimization Specialist (`cost_optimizer`)**: Receives delegated resource metadata to detect oversized compute instances and recommend right-sizing strategies (~42% monthly savings).
3. **Cross-Domain Agent Federation**: Supports decentralized policy negotiation and manifest handshakes with external agentic web domains.
4. **Pluggable Inference (BYOK)**: Executes out-of-the-box via a deterministic zero-cost policy engine, or connects to custom OpenAI-compatible endpoints stored strictly in local browser storage.
